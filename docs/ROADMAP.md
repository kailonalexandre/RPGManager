# Roadmap

## Curto Prazo

- Dividir `frontend/src/App.tsx` em módulos por domínio.
- Criar testes de integração cobrindo permissões críticas.
- Criar testes E2E para fluxo completo do usuário.
- Melhorar validações visuais e mensagens de erro no frontend.
- Documentar exemplos completos de payload de personagem.

## Médio Prazo

- Melhorar modo offline/PWA com estratégia de cache mais refinada.
- Adicionar storage externo opcional para imagens.
- Criar gerenciamento de membros de campanha.
- Melhorar exportação PDF com template dedicado e paginação mais controlada.
- Adicionar auditoria simples de alterações importantes da ficha.

## Longo Prazo

- Automação opcional de regras por sistema/classe.
- Suporte a múltiplos sistemas de RPG além do modelo atual.
- Biblioteca pública moderada por instância.
- Importadores adicionais apenas para fontes abertas/licenciadas.
- Permissões mais granulares para coedição de fichas.

## Fora do Escopo Atual

- Distribuir conteúdo protegido de livros oficiais.
- Automatizar todas as exceções de regras de D&D ou qualquer outro sistema.
- Marketplace público de conteúdo.
